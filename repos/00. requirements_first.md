\# 트리플-NOL 합병 기반 차세대 iOS 여행 경비 관리 애플리케이션

\## 요구사항 명세서 및 개발 계획서 (실시간 환율 연동 통합본)



\---



\## 1. 요구사항 명세서 (Requirements Specification)



\### 1.1. 시스템 개요

본 애플리케이션은 파편화된 여행 준비, 경비 기록, 정산 과정을 단일 플랫폼으로 통합하는 가이드형 스마트 관광 애플리케이션입니다. 실시간 환율 API 연동을 통한 다중 통화(Multi-currency) 처리, 온디바이스 AI를 활용한 프라이버시 보호, 그리고 다자간 정산 알고리즘을 통해 인지적 마찰을 최소화하는 것을 목표로 합니다.



\### 1.2. 기능적 요구사항 (Functional Requirements)



\*\*가. 다중 통화 실시간 변환 및 정산 (Real-time Multi-Currency)\*\*

\* \*\*기준 통화(Base Currency) 설정:\*\* 사용자는 애플리케이션 초기 설정 시 정산의 기준이 되는 통화(예: KRW, USD)를 설정할 수 있습니다.

\* \*\*실시간 환율 동기화 및 듀얼 모드 지원:\*\*

&#x20; \* \*\*결제 시점 고정 모드:\*\* 지출 발생 시점의 실시간 환율을 API로 불러와 기록에 영구 고정(결제 금액, 통화, 적용 환율, 기준 통화 환산 금액 저장).

&#x20; \* \*\*정산 시점 실시간 모드:\*\* 정산(Split)을 실행하는 순간의 최신 환율을 일괄 적용하여 채권/채무액을 유동적으로 계산.

\* \*\*교차 환율(Cross Rate) 자동 계산:\*\* API가 제공하는 기축 통화를 기준으로 제3국 통화 간의 교차 환율을 앱 내부에서 자동 연산합니다.



\*\*나. 상태 기반(State-driven) 맞춤형 UI 제공\*\*

\* \*\*여행 전 (Pre-trip):\*\* 예산 수립, 목적지 통화 환율 설정 인터페이스 전면 배치.

\* \*\*여행 중 (During-trip):\*\* 실시간 지출 기록, 영수증 스캔 모달, 환율 변환기 위주의 UI 노출. 환율 변동 넛지(Nudge)를 통해 유리한 정산 시점을 안내.

\* \*\*여행 후 (Post-trip):\*\* 리뷰 작성 유도, 다중 사용자 간 경비 정산, 카테고리별 통계 리포트 화면으로 전환.



\*\*다. 지능형 영수증 스캔 및 데이터 정형화\*\*

\* `VNDocumentCameraViewController`를 활용하여 영수증 사각형을 자동 식별 및 캡처합니다.

\* Vision Framework의 텍스트 추출 모드를 통해 좌표 기반 텍스트 행을 병합합니다.

\* Apple Intelligence(`FoundationModels`)를 활용하여 영수증 텍스트를 상호명, 날짜, 금액 등으로 정형화(Swift Struct)하며, 통화 기호($, ¥, € 등)를 ISO 4217 통화 코드로 자동 매핑합니다.



\*\*라. 다중 사용자 간 최소 트랜잭션 정산 (Split)\*\*

\* 모든 사용자의 지출/부채 내역을 기준 통화(Base Currency)로 전처리(Preprocessing)하여 변환합니다.

\* 각 참여자의 순 잔액(Net Balance) 산출: `Net\_Balance(i) = Sum(Base\_Receivables) - Sum(Base\_Payables)`

\* 채권자(양수)는 Max-Heap, 채무자(음수)는 절댓값 기준 Min/Max-Heap에 적재한 뒤, 탐욕적(Greedy) 상계 처리로 송금 횟수를 최소화(최대 N-1번)합니다.



\### 1.3. 비기능적 요구사항 (Non-Functional Requirements)



\* \*\*성능 및 동시성 제어:\*\* 환율 계산, 대량 데이터 내보내기, 정산 알고리즘 연산은 `@ModelActor` 환경에 격리하여 메인 UI 스레드 프리징을 완벽히 차단합니다.

\* \*\*프라이버시 및 보안:\*\* 영수증 데이터 분석을 포함한 기계 학습 연산은 외부 서버 전송 없이 온디바이스(On-device) Neural Engine에서 처리됩니다.

\* \*\*오프라인 가용성(Offline Availability):\*\* 네트워크 연결 시마다 최신 환율 데이터를 영구 저장소에 캐싱하여, 로밍이 단절된 오프라인 환경에서도 마지막 캐싱 시점의 환율로 애플리케이션이 구동되도록 설계합니다.



\### 1.4. 시스템 아키텍처 및 데이터베이스 제약사항



\* \*\*아키텍처 패턴:\*\* MVVM (Model-View-ViewModel) 채택.

\* \*\*환율 네트워킹 계층:\*\* REST API를 `async/await` 동시성 모델로 캡슐화한 `CurrencyService` 클래스를 구축합니다.

\* \*\*CloudKit 충돌 방지 설계 (SwiftData):\*\* 

&#x20; \* `@Attribute(.unique)` 매크로 사용 금지.

&#x20; \* 관계형 데이터(`@Relationship`)는 양방향 옵셔널 처리 및 역방향 참조 명시.

&#x20; \* 논리적 삭제 구현 시 시스템 예약어를 피해 `isHidden` 또는 `appIsArchived`로 명명.

\## 2. 개발 계획서 (Development Plan)



\### 2.1. 개발 환경 및 기술 스택



| 구분 | 적용 기술 및 프레임워크 |

| :--- | :--- |

| \*\*Language / UI\*\* | Swift 6.0, SwiftUI, MVVM Architecture |

| \*\*Data Persistence\*\*| SwiftData, CloudKit (`NSPersistentCloudKitContainer`) |

| \*\*Network \& API\*\* | `URLSession` (`async/await`), ExchangeRate-API |

| \*\*Concurrency\*\* | `@ModelActor`, `BackgroundTasks` |

| \*\*Computer Vision\*\* | VisionKit (`VNDocumentCameraViewController`), Vision |

| \*\*AI / NLP\*\* | Apple Intelligence (`FoundationModels`, `@Generable`) |

| \*\*Algorithm\*\* | Swift Collections (Heap), Greedy Algorithm |

| \*\*Visualization\*\* | SwiftUI Charts (`SectorMark`, Donut Chart) |

| \*\*Testing\*\* | Swift Testing (Parameterized Tests) |



\### 2.2. 단계별 개발 일정 (총 8주 스프린트)



\* \*\*Phase 1: 아키텍처 설계, DB 구축 및 실시간 환율 파이프라인 (1\~2주차)\*\*

&#x20; \* MVVM 디렉토리 구조 및 GitHub 리포지토리 설정.

&#x20; \* SwiftData 모델 스키마 정의 (`Expense` 모델 내 다중 통화 속성 포함).

&#x20; \* `CurrencyService` 클래스 개발, 환율 API 연동 및 오프라인 대비 로컬 캐싱 구현.

&#x20; \* `BackgroundTasks`를 통한 주기적 환율 갱신 스케줄러 등록.



\* \*\*Phase 2: 코어 엔진 및 다중 통화 정산 알고리즘 융합 (3\~4주차)\*\*

&#x20; \* 온디바이스 AI 기반 지능형 영수증 스캐너(`UIViewControllerRepresentable` 래퍼) 개발.

&#x20; \* 통화 기호 자동 파싱 및 기준 통화(Base Currency) 전처리 모듈 구축.

&#x20; \* Swift Collections 힙(Heap) 기반 다중 사용자 간 정산(Split) 알고리즘 구현.

&#x20; \* `@ModelActor`를 활용한 백그라운드 데이터 격리 연동.



\* \*\*Phase 3: 상태 기반 UI/UX 및 차트 구현 (5\~6주차)\*\*

&#x20; \* 여행 시점(전/중/후)에 따른 홈 화면 동적 라우팅 시스템 적용.

&#x20; \* 실시간 환율 변동에 반응하는 정산 예상 금액 ViewModel 바인딩 및 현지/환산 통화 스왑(Swap) UI 개발.

&#x20; \* SwiftUI Charts 기반 예산 렌더링(도넛 차트) 및 카테고리별 대시보드 구축.



\* \*\*Phase 4: 동기화, QA 및 릴리즈 준비 (7\~8주차)\*\*

&#x20; \* CloudKit 다중 기기 실시간 동기화 테스트 및 충돌(Conflict) 해결 시나리오 점검.

&#x20; \* Swift Testing 프레임워크를 활용한 환율 API 극한 값(오프라인, 응답 지연 등) 매개변수화 단위 테스트 수행.

&#x20; \* App Store 배포 준비 및 API 호출량 제한(Rate Limit) 방어를 위한 클라이언트 최적화.
